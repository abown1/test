# 網頁版怎麼放上網站

這包是 Godot 4.5 的網頁輸出，給《仙武之體》單人版用。多執行緒是關的，所以**不用**在 Cloudflare 加 `Cross-Origin-Opener-Policy` 或 `Cross-Origin-Embedder-Policy`。

把這個資料夾整個當成靜態網站即可。入口是 `index.html`。同目錄的 `index.js`、`index.wasm`、`index.pck` 必須一起在，不能拆開。

Cloudflare Workers 靜態網站（或 Pages）直接上傳這個資料夾。不要另外加 COOP／COEP 標頭。如果以後改回有多執行緒的輸出，才需要這兩條：

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

這次的 `index.html` 裡 `GODOT_THREADS_ENABLED` 是 false，不需要那兩條。

舊版網頁存檔還在瀏覽器的 `localStorage`（`xianwu_demo_save_v3`、`xianwu_slot_` 開頭）和 IndexedDB `xianwu_saves`。新版只會讀，轉入後寫到另一把鑰匙 `xianwu_godot_save_v1`，不會蓋掉舊的。
